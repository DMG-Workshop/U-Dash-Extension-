# U-Dash Extension

A lightweight, fully private productivity dashboard and bookmark manager built for homelabs, but perfect for everyday tasks. 

No cloud. No tracking. No telemetry. Just a solid, fast tool that actually works.

## Features

* **Custom New Tab Dashboard:** Organize your local services, IP addresses, and web links into folders on a clean grid. 
* **Integrated RSS Reader:** Fetch XML feeds directly to your dashboard. Read what you want to read, without an algorithm force-feeding it to you.
* **Mini Dropdown Menu:** Click the extension icon for quick access to recently saved links and a persistent scratchpad for jotting down notes or IPs.
* **One-Click Saving:** Save your current active tab instantly.
* **Complete Data Portability:** Export and import your entire layout via a simple JSON backup. Your data belongs to you.
* **100% Offline & Private:** U-Dash doesn't phone home. Everything is stored purely in your browser's local storage. We didn't need the cloud to save a bookmark in 1998, and we don't need it now.

## Installation

### Firefox
1. Download the latest `.xpi` file from the **Releases** tab on the right side of this page.
2. Drag and drop the `.xpi` file directly into your Firefox browser window to install it.
3. *(Developer route)*: Type `about:debugging` in your URL bar, click **This Firefox**, click **Load Temporary Add-on**, and select the `manifest.json` file.

### Chrome / Brave / Edge
1. Download this repository as a `.zip` and extract it to a folder.
2. Type `chrome://extensions/` in your URL bar.
3. Toggle **Developer mode** on in the top right corner.
4. Click **Load unpacked** and select the extracted folder.
